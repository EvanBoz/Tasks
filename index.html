Guide

Adding and editing

  • New task (or press n) opens the task menu. Each column also has an Add task button that pre-fills that column's status, tag, priority or due bucket. Clicking an empty calendar day pre-fills that date.
  • Every card has one Edit button (or double-click the card). The same menu holds everything: title, notes, tag, priority, status, start/due date and time, estimate, repeat, subtasks, timer, pin, archive, duplicate and delete.
  • Save applies changes. Cancel discards them. New tasks need a title.
  • Delete moves a task to Trash. Show: Trash lets you Restore it or delete it forever. Undo also brings it back.

Header

  • Board / List / Calendar / Stats: columns, one long list, month grid by due date, totals and charts.
  • Search matches titles, notes, subtasks and tag names. Esc clears it.
  • Undo / Redo: last 60 changes this session (lost on reload; settings changes aren't included).
  • Open: loads a .task file. In Chrome/Edge it also links the file so later changes auto-save to it. If you already have tasks you're asked: OK = replace, Cancel = merge (adds only tasks you don't have, keeps your settings).
  • Save: Chrome/Edge asks where once, then auto-saves ("Save now" forces it). Other browsers download a new .task file each time. Files are named like 001-1126.task (save number, then month and year). The number goes up with each new file you save that month and restarts at 001 the next month.

Filter bar

  • Group (Board only): Status, Tag, Priority or Due date. Dragging a card to another column changes that field.
  • Sort: Due date, Priority, Tag, Newest, A-Z, Added order. Pinned tasks always sit at the top.
  • Tag / Priority / When filter what's shown; Show switches Active, Archived, Trash. If something seems missing, check these and the "Show completed tasks" setting. Filters only hide, never delete.

Cards

  • Checkbox: marks done and records the completed date. Unticking clears it.
  • The dot before the title is priority, the colored edge is the tag. Due dates turn orange on the day. Past-due tasks get a red outline and an "Overdue" label, and a banner at the top counts them (and tasks due today) with a button to show only those. A task due today with a time counts as past due once that time passes.
  • Subtasks: the "2/5 subtasks" button shows a checklist you can tick on the card; a bar shows progress. A second bar appears when a task has an estimate.
  • Ctrl/Shift-click selects several cards; a bar appears to mark done, archive, delete, or set tag/priority. Esc deselects.

Timer and estimate

  • The timer is a stopwatch: Start/Stop it in the Edit menu and time adds up across sessions. It keeps counting if you close the page.
  • With an estimate it also counts down ("12m left", then "5m over" in red) and a reminder appears when you reach it (only while the page is open). Completing or deleting a task stops its timer.

Repeating tasks

  • Completing a repeating task creates the next one (due date moves forward from the old due date, or from today if none; subtasks reset) and the finished one stops repeating, so no doubles.

Calendar and Stats

  • Calendar shows tasks with a due date (4 per day, then "+n more"). Click a chip to edit, drag it to reschedule, click an empty day to add a task for that date.
  • Stats are calculated from your tasks, so they live in your .task file. Archived and trashed completed tasks still count; emptying the trash removes them.

Saving and safety

  • Your .task file is the real save: tasks, trash, tag names, settings and your current view. It's plain JSON. Older .taskboard and .json backups still open.
  • The browser keeps a safety copy too, but clearing site data or private windows wipes it, so keep a file.
  • Orange status = unsaved changes. You also get a backup reminder after the number of days you set, and a warning when closing with unsaved changes (unless a file is linked).
  • No syncing: each device has its own copy. Save, then Open that file elsewhere. If two devices both edit, the last save wins.
  • Nothing is uploaded. GitHub Pages only serves the page.
  • Unreadable file: you'll see "Could not read that file" and nothing changes. Dates use your device's local time. Turning a feature off in Settings only hides it; its data stays.
  • Shortcuts: n new task, / search, 1-4 views, Ctrl+Z / Ctrl+Y undo/redo, Ctrl+S save, Esc clear, ? guide. Drop a .task file anywhere to import it.
